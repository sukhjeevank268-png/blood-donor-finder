# 🩸 Blood Donor Finder

## About the Project
Blood Donor Finder is a C++ console-based application developed to manage blood donor information and make it easier to find donors according to their blood group and city.

The project demonstrates the practical implementation of Object-Oriented Programming (OOP), data structures and file handling in C++.

## 🎯 Objectives
- To maintain donor information systematically.
- To search donors based on blood group and city.
- To provide options to add, update and delete donor records.
- To store donor information permanently using file handling.
- To develop problem-solving and programming skills using C++.

## ✨ Features
- Add new donor details.
- Display all registered donors.
- Search donors by blood group.
- Search donors by city.
- Update existing donor information.
- Delete donor records.
- Save and load records using file handling.
- Validate donor age, blood group and phone number.

## 🛠️ Technologies Used
- Programming Language: C++
- Concepts: Object-Oriented Programming (OOP)
- Data Structure: Vector
- File Handling: Text File (donors.txt)
- IDE: Visual Studio Code

## 📂 Project Structure
- `project.cpp` – Main source code.
- `donors.txt` – File used to store donor records.
- `Blood_Donor_FinderProjectProposal.pdf` – Project proposal document.

## ▶️ How to Run

**Step 1:** Clone the repository.

```bash
git clone https://github.com/YOUR-USERNAME/Blood-Donor-Finder.git
```

**Step 2:** Open the project folder.

```bash
cd Blood-Donor-Finder
```

**Step 3:** Compile the program.

```bash
g++ main.cpp -o main
```

**Step 4:** Run the application.

```bash
./main
```
